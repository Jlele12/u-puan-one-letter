Entry for make.fun's **One Letter for Your Day**: the program writes exactly one
letter, `S` — standing for **"slogged"**, the word for a day of grinding bounties,
checks and retries — to `/output/entry.txt`.

Run: `python3 main.py` (writes `/output/entry.txt`, 1 byte: `S`).
